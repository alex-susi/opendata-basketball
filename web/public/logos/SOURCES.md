# Team logos

Club crests for the 17 teams in the ten sample games, downloaded on 2026-11-07 from TheSportsDB
(https://www.thesportsdb.com, free API key "123"; images on r2.thesportsdb.com). Each file is named by the team id used
in `data/matches.json`; `logos.json` lists them for the site. They are decoration only: no analysis reads them.

The crests are the clubs' trademarks. TheSportsDB's current badge is used, so two reflect 2026-27 rebrands rather than
the 2025-26 season: 1330 (shown as "Kids&Us Manresa", BAXI Manresa in 2025-26) and 1339 ("Fundación Unicaja
Baloncesto", Málaga).
